Adding a model to the library

1. Generate it (Tripo / Meshy) and download the .glb.

2. Compress it — raw generations are 40–60 MB and will choke a browser. Quantize is the right codec here: it decodes natively, unlike draco/meshopt which need an extra decoder the preview browser blocks.

npx @gltf-transform/cli optimize "IN.glb" "OUT.glb" --compress quantize --simplify-error 0.004 --texture-size 1024

3. Drop it in public/models/ (or public/avatars/ for an agent persona) and add one line to the MODELS array in this page.

Typical result: 60 MB → ~600 KB (99% smaller) with no visible quality loss at display size.
